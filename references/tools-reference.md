### ⚠️ 避免的常见错误

| 错误做法 | 正确做法 | 原因 |
|---------|---------|------|
| 用流程图处理一切逻辑 | 条件组合→判定矩阵，状态→决策矩阵 | 流程图无法表达复杂条件的正交关系 |
| 缩进嵌套表达条件 | 改用表达式树或判定矩阵 | 当当当当格式编写/阅读/维护都困难 |
| 文字描述时序关系 | 改用时间轴或泳道图 | 纯文字无法直观看到时间边界和角色分工 |
| 表格内仍写长句子 | 继续拆分或独立引用 | 表格+长句违背了表格"一目了然"的优势 |
| 同类事物用不同工具 | 保持工具一致性 | 规则不统一造成理解困难 |
| 自定义非标准符号 | 使用UML/BPMN标准符号 | 非标准符号造成沟通障碍 |
| 图表有两个出口 | 确保单一终点 | 多出口造成流程路径不确定 |
