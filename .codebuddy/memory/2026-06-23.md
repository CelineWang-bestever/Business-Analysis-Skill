### Business-Analysis-Skill 工具解耦改造

**问题**：项目 SKILL.md 的 YAML 头（name/trigger.keywords）和 README 安装路径硬编码了 CodeBuddy，其他用户下载后被迫安装到 CodeBuddy。

**改造内容**：
1. **SKILL.md** — 移除 CodeBuddy 专属 YAML 头，变为工具无关的纯提示词核心
2. **tool-configs/ 目录** — 新建 6 个工具的专属配置：
   - `codebuddy/SKILL.md` — 原 CodeBuddy 格式（YAML 头 + trigger.keywords）
   - `trae/business-analysis.md` — TRAE 格式（alwaysApply + description，放 .trae/rules/）
   - `cursor/business-analysis.mdc` — Cursor Rules 格式（放 .cursor/rules/）
   - `windsurf/.windsurfrules` — Windsurf 格式（项目根目录）
   - `cline/.clinerules` — Cline 格式（项目根目录）

3. **README.md** — 重写安装部分，覆盖 6+ 工具的安装说明，明确 references/ 是给人看的无需复制

**关键决策**：
- SKILL.md 是自包含的，references/ 是进阶阅读材料，不需要复制到工具配置中
- 各工具配置文件嵌入完整的分析逻辑（非文件引用），确保独立可用
